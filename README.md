# NASTV Lite

**NASTV Lite** 是一套专为飞牛 NAS（fnOS `x86_64` 原生 `.fpk`，无需 Docker）与车机/Android TV 打造的**双模轻量化流媒体系统**。

## 核心特性

### 1. 服务端（Go 原生单二进制 · 飞牛 `.fpk` 打包）
- **双模式媒体库**：
  - **🎬 影视剧模式**：自动识别 `S01E01` / `第X集` 与本地 `.nfo` / 海报墙。
  - **📁 纯文件夹模式**：1:1 映射磁盘真实多级目录树，不做强行聚合，适合 MV、儿童动画短片、教育资料、家庭录像，并自动通过 `ffmpeg` 抽取视频首帧封面。
- **多用户与媒体库权限隔离**：支持创建多账号（如儿童账号、车机专用账号），按媒体库勾选可见权限。
- **FFmpeg 硬解转码**：调用宿主机 `ffmpeg` 与 `/dev/dri/renderD128`（VAAPI），支持原画直出（HTTP Range）与多档 HLS（1080P / 720P / 480P / 360P / 纯音频）。
- **IPv4 / IPv6 双栈 & 在线自动更新**：默认双栈监听 `:5678`，Web 管理台支持目录可视化浏览与一键在线升级。

### 2. 客户端（Android TV / 车机适配版）
- **IPv4 / IPv6 双栈直连**：支持裸 IPv6 地址自动方括号补全、IPv4 与双栈域名。
- **弱网高容错播放**：支持设置**默认起播清晰度**、**播放器缓冲区大小**（15s / 50s / 120s 隧道大缓冲）及**断线重连 + 原画自动降级 720P**。
- **车机/TV 专属体验**：播放模式切换（列表/随机/单曲）、息屏听歌防眩目、开机自动继续播放、拼音首字母搜索、人声对白增强 (+6dB)、应用内自动更新。

## 快速开始
1. 在飞牛 fnOS **应用中心 -> 手动安装** 上传 `nastv-lite-x86_64-v1.0.0.fpk`。
2. 打开桌面图标 **NASTV Lite**（或访问 `http://<NAS-IP>:5678`），默认管理员账号 `admin` / `admin123`。
3. 添加媒体库并选择「纯文件夹模式」或「影视剧模式」，按需创建子账号并分配媒体库权限。
4. 在车机/电视端安装 `NASTV_Lite_v1.0.0.apk`，输入 NAS IPv4/IPv6 地址与端口 `:5678` 登录即可。
